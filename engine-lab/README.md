# ENGINE STUDIO · 发动机构造与原理实训

打开 `发动机构造与原理实训.html` 即可使用完整课件。单文件约660KB，已内嵌三维引擎、交互逻辑和全部内容，不需联网或安装。建议使用支持WebGL和硬件加速的现代桌面浏览器；已在本机Google Chrome验证。参考来源链接只在主动点击时访问网络。

## 教学内容

12个本科教学单元；两大机构与五大系统为主干，补充进排气增压、柴油机对照、几何/功率计算、拆装与缸径测量、综合诊断。课程范围依据大学公开《汽车构造》教学大纲核对，详见 `docs/01-课程知识体系.md`。

- 可旋转、缩放、点选的四缸DOHC模型；装配/剖切/分层爆炸/单缸观察。
- 720°转角拖动、慢放、四缸状态、活塞位移曲线；理想气门启闭。
- 12份任务单、38项自记录任务、24道单选题及解析。
- 排量/压缩比/功率计算、缸径三截面双方向测量记录与计算。
- 本机进度、笔记和评分保存；导出Markdown实训报告及PNG模型截图。
- 桌面/手机适配、键盘操作、教师导学、课程来源说明。

## 模型与专业边界

通用直列四缸、四冲程、DOHC、16气门、PFI汽油机。缸号由正时端向飞轮端为1—4；示例发火顺序1—3—4—2。0°为1缸进气上止点，四冲程边界为0/180/360/540/720°。曲轴转两周、凸轮轴转一周；示意正时轮20:40齿。

活塞位置按精确平面曲柄滑块约束计算，模型运动满足连杆长度。模型采用理想、无间隙的刚性机构；气门升程由理想函数驱动，凸轮轮廓按各缸事件相位示意，未建立真实接触动力学。实际配气早开晚关与重叠在文字中讲解。色块不表示压力/温度/火焰仿真，油水路线是拓扑示意。爆炸图用于认识总成层级，不是完整拆装顺序。

几何比例、材料外观和紧固件为教学表达，没有对应量产机型CAD、载荷、有限元、CFD或维修认证依据。真实扭矩、正时、间隙、油压和报废限值必须查对应机型手册。投课前需由任课教师结合教材版本与实验台架复审。本项目完成的是经过功能与画面验证的教学工程交付，不宣称通过工业或课程机构认证。

## 使用

- 拖动旋转、滚轮或触控缩放；点击部件或选择右侧部件列表。
- 三维页面空格播放/暂停；左右方向键每次5°；R复位视角。表单输入不触发快捷键。
- 爆炸视图暂停机构播放；拖动“分解距离”改变层级间距。
- 原理页、实训页和自测页在顶部切换；课程目录在手机上通过菜单展开。
- 保存只发生在当前浏览器本机；文件移动或浏览器清理数据可能影响记录，建议及时导出报告。源代码不上传学习数据。

## 源码开发

`dist/` 是可通过本地HTTP服务运行的模块源码，`vendor/` 已附Three.js及MIT许可证。直接用file方式打开 `dist/index.html` 可能被浏览器模块策略阻止，请打开根目录的单文件版。

```sh
npm ci
npm run check
npm run build
npm start
```

预览地址 `http://localhost:8765`。`scripts/build.mjs` 用esbuild生成根目录的离线HTML，不依赖CDN。依赖锁定在package-lock.json中。

`qa/verify.cjs` 和 `qa/offline.cjs` 是浏览器验证脚本。默认使用可解析的Playwright及其Chromium；也可通过PLAYWRIGHT_MODULE与CHROME_PATH环境变量指定本机运行时。模块版验证需要先运行npm start。
