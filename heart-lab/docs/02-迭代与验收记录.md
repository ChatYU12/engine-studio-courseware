# 迭代与验收记录

日期：2026-10-19（Asia/Shanghai）

## 迭代记录

1. **先定课程架构**：按系统解剖结构 → 心肌电生理 → 专门传导系统 → ECG 与机械活动 → 心动周期 → 体肺循环串联动力学 → 综合实训建立知识地图。把解剖模型、动画时钟、曲线、瓣膜矩阵、学习任务一一对应，详见 01-课程知识体系.md。
2. **实现三维模型与交互**：用本地 Three.js 创建四腔心切面示意、房间隔/室间隔、四瓣、大血管、冠状血管、腱索/乳头肌及传导通路。加入前/后/左/右视角、旋转缩放、图层开关、结构选择说明和心动周期联动。
3. **课程模块联动**：统一 0.8 s、75 次/分的教学时钟，连动传导图、ECG、左右心压力曲线、左室容积、四瓣状态与循环路径高亮。增加动作电位、自律性/兴奋性/传导性/收缩性、教师导学、4 项观察任务、8 题即时测验和引用资料。
4. **压力交叉自检与修正**：首轮发现等容收缩末/等容舒张始的瓣膜状态已变更，但示意曲线并未恰好在同一边界与动脉压相交。调整左右室和对应动脉压力曲线，使等容收缩末室压达到对应动脉压、射血期室压高于动脉压，射血末压差反转，等容舒张开始。播放速度变量也与界面默认的 0.45× 对齐。

## 教学模型边界

模型以空间关系和识别任务为目标，三维几何为原创的简化教学形态，不按患者影像比例重建；电传导金线为相对位置示意，不表示肉眼可见的粗大索条；压力/流量动画是概念性呈现，不是 CFD。课件已列出公开解剖、生理来源，仍由授课教师按指定教材与教学进度复核。
