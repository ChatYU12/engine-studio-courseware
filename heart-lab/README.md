# 心脏解剖与泵血机制实训

面向大学人体系统解剖学与生理学的中文单页实训课件，包含三维心脏示意模型、电活动与传导、心动周期压力/瓣膜/容积联动、体肺循环动力学、实训任务及形成性测验。

## 使用

直接用现代桌面或移动浏览器打开 心脏解剖与泵血机制实训.html。成品已将 HTML、CSS、JavaScript、Three.js 与 OrbitControls 打包在一个文件内，运行不需要网络或服务端。参考文献链接需要联网查看。

## 项目结构

- src/：可维护源码（HTML/CSS/ES modules 与本地 Three.js 依赖）
- docs/01-课程知识体系.md：开发前确定的知识地图、心动周期状态表、三维设计及验收要求
- docs/02-迭代与验收记录.md：本轮迭代与验收记录
- scripts/build.mjs：构建单文件离线版本
- 心脏解剖与泵血机制实训.html：交付课件

## 本地构建

需要 Node.js：

~~~sh
npm install
npm run check
npm run build
~~~

成品几何、压力图与周期数值用于教学示意，不是临床患者影像、诊断工具、CFD/有限元仿真或医学器械认证产品。课程投用前请授课教师按学校指定教材版本复核。
