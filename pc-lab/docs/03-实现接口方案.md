# 实现接口方案（前置设计）

本方案先于代码确定，用于模型、课程数据和界面分工。课程事实以 `01-课程知识体系.md` 为准。

## 稳定部件 ID

`chassis`, `panel`, `standoffs`, `ioShield`, `motherboard`, `cpu`, `cooler`, `ramA2`, `ramB2`, `ssd`, `m2Shield`, `psu`, `atx`, `eps`, `frontIO`, `fans`, `sataSSD`, `sataData`, `sataPower`, `gpu`, `gpuPower`。

CPU／散热器／内存／M.2 是主板子装配，主板从台面移入机箱时已经安装的子件应随主板移动。显卡单独从服务侧对齐插入，显卡风扇朝下；电源在机箱底部后方。机箱侧板最后封合。线缆只在对应教学步骤出现，接口形状与用途可辨认。

## 场景接口

`createPCScene(container, {onSelect})` 返回：

- `setState({amounts, explosion, selected, isolated, labels, mode})`：amounts 是 ID 到 0–1 的装配进度；观察模式全部为 1；爆炸 0–1 可单独调节；selected 高亮；isolated 是单件 ID 或 null。
- `setView(name)`：`iso`, `side`, `rear`, `top`；`resetView()`。
- `focusPart(id)`：可选，聚焦部件；`capture()` 返回 PNG 数据 URL。
- `getStats()`：绘制调用数、三角形等真实运行数据；`dispose()`。

场景负责响应容器尺寸变化、OrbitControls、拾取、标签投影和渲染；界面只传明确状态，不跨模块修改场景内部对象。阶段动画由界面对各 amount 插值；减少动态效果时直接落到终态。未安装部件采用独立待装位置或隐去并提供清晰活动件预览，不与已安装部件重叠。

## 数据接口

`PARTS`: `{id, name, en, spec, description, location, precautions, sources}` 数组。

`STEPS`: `{id, title, short, chapter, partIds, installIds, removeIds, duration, instruction, checks, warning, principle, sources}` 数组。首项准备阶段只保留机箱结构，其后以 installIds/removeIds 明确装配状态。检查与通电阶段不增加假部件。拆卸单独定义安全步骤后按照实物依赖逆转，不直接逆转通电操作。

`QUIZ`: `{id, question, options, answer, explanation}` 数组，answer 为从0开始的正确项索引。

`SAFETY_CHECKS`: `{id,text}` 数组；`SOURCES`: `{id,title,url,note}` 数组；`PLATFORM`: `{title,description,specs}`。

## 完成标准

三种视图与装配／拆卸切换不互相残留错误状态；进度改变、暂停、切步骤、切模式都可预测；检查项和题目保存本机；报告能导出；无后端和外部资产加载依赖；单文件可 file:// 使用。
