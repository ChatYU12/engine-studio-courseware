版本：1.0；建立日期：2026-10-20；状态：知识与验收基线已建立，应用实现与浏览器验证待执行。

## 5. 必测用户路径与证据

1. **首次学习：** 打开页面 → 认识固定平台 → 安全检查 → 完整装配 → 通电前检查 → POST/UEFI → 结束工位。
2. **结构探索：** 爆炸滑块全范围 → 点选 CPU/背板/内存/NVMe/GPU/电源 → 切视角 → 合拢复位。
3. **逆序拆卸：** 从完整整机进入拆卸 → 断电 → 解 GPU 线/螺钉/卡扣 → 后续组件拆除 → 散热器解黏连 → CPU 安全收纳。
4. **典型错误：** EPS/PCIe 错选、A2/B2 判断错误、显示线接主板、空盘无启动项、显卡未解卡扣、散热器猛拔；应得到原因反馈而非错误成功动画。
5. **学习报告：** 正确、部分错误与关键安全项错误三组结果 → 查看评分 → 修正学习 → 导出或恢复记录。
6. **恢复稳定性：** 动画中切模式/重置 → 调整窗口大小 → 刷新/重新载入 → 记录与视觉状态符合明确设计。

证据至少包括整机默认、爆炸、CPU/背板、A2/B2、供电路线、装配中间工位、拆卸前提、故障反馈、成绩与窄屏截图。检查记录注明实际验证的版本、浏览器和未完成项。

## 6. 自迭代规则

每轮按“检查一条完整路径 → 记录可复现问题 → 修复最严重问题 → 重测受影响路径”推进。知识错误、安全前提缺失、打不开、核心按钮无效属于阻断，优先于装饰性视觉微调。所有阻断项清零、必须项实际通过、交付资料齐备后即可完成；不为延长循环而反复增加范围。

额度或外部环境不足时，保存已完成阶段、正在处理的问题、文件位置、复现方法和下一步动作；下一次可用执行从断点恢复。待验证不能改记通过。课件交付完成后，按主任务安排停止后续自动唤醒。
