# 3D 电脑主机搭建与拆解实训：课程知识体系

版本：知识基线 1.0；核验日期：2026-10-20（北京时间）。

本课使用一套固定的 AM4 / DDR4 / ATX 台式机平台，训练“识别—兼容性核对—规范装配—通电检查—故障定位—规范拆卸”。3D 模型是教学结构示意，不承担机械尺寸、力矩或电气测量功能。爆炸视图用于观察层级，实训步骤必须遵守实际的机械和电气前置条件。

## 2. 学习目标与知识结构

完成课程后，学员应能够：

1. 在整机和爆炸视图中辨认至少 12 类对象，并说明 CPU 运算、内存暂存、SSD 持久存储、显卡图形处理、主板互联、电源供电和散热器导热的作用。
2. 根据插座、缺口、丝印、接口类别与说明书判断兼容性，避免用“插得进去”代替兼容性核对。
3. 按前置条件完成 AM4 平台的 20 个装配工位，口述每个关键动作的检查点。
4. 区分“有风扇转动”“完成 POST”“进入 UEFI”“能引导操作系统”四种不同状态。
5. 通过现象、供电检查与 EZ Debug 状态提出下一项验证动作，避免凭一个灯直接断言器件损坏。
6. 在完全断电后按解除约束的顺序拆卸，特别处理显卡卡扣和散热器导热膏黏连。

建议课时：2 × 45 分钟。第 1 课时覆盖安全、部件识别和装配；第 2 课时覆盖故障、拆卸与测评。时间是教学安排建议，不是实际装配速度考核标准。

## 3. 安全、工位与工具

操作内部器件前，正常关机，将电源开关置于 O，并拔下交流电源线；确认系统不再处于通电状态。使用符合实训室要求的 ESD 工作台与接地点，按实验室规范连接防静电手环。拿主板和扩展卡的边缘，不摸金手指、CPU 针脚和插座触点。主板置于干净、稳定的防静电工作垫上。[S1][S4]

工具包括合适规格的十字螺丝刀、分格螺钉盒、标签、说明书、必要的清洁用品与导热材料。螺钉按用途分类：主板支柱/主板固定螺钉、机箱/电源螺钉、M.2 小螺钉不能凭外观混用。不得用电动工具高速拧紧，不以课件动画推定手感或力矩。

通电前清点螺钉和金属异物；确认机箱中没有多余支柱顶住 PCB。电源作为封闭模块识别和拆装，不打开电源外壳，不进行交流侧或电源内部维修。不得带电插拔内部组件；闻到焦味、发现液体、冒烟、异常发热或破损时停止操作并交由教师处理。

新散热器如果已有完整预涂导热膏，不叠加涂抹；重新安装则清理旧膏后按散热器/导热材料要求施工。保护膜或盖仅在产品实际存在时移除，不能把所有产品都教成“必有一层膜”。[S4]

## 4. 核心接口知识卡

| 对象 | 正确连接与观察点 | 典型错误及解释 |
| --- | --- | --- |
| AM4 CPU | 抬起插座锁杆，按双方三角标识对齐，CPU 自然落座后锁杆 | 用力按压纠正方向会损坏针脚；CPU 未锁定不能安装散热器 |
| 散热器 | 本课为弹簧螺钉型；背板在主板后方，四螺钉对角逐次固定 | 不能演示为 Wraith Prism 的挂钩/凸轮扳手安装法；不能丢弃背板 |
| DIMM | 靠 CPU 向外依次核对 A1、A2、B1、B2；本课 A2/B2 | “有四槽就插相邻两槽”错误；应先核对丝印、缺口和卡扣 |
| M2_1 | 顶部 CPU 直连槽；本课 2280 NVMe；有相应长度支柱与散热片 | 先拆散热片，再斜插/压平/固定；支柱位置错误会使 SSD 弯曲 |
| PCI_E1 | 本课单显卡使用靠 CPU 的第一条长 PCIe 插槽 | 长插槽不一定全是 x16 电气通道；不可只凭长度选择 |
| ATX_PWR1 | 24-pin 主板主供电，核对锁扣 | 接上 24-pin 不代表 CPU 供电也已完成 |
| CPU_PWR1 | EPS 8-pin（4+4），来自标注 CPU/EPS 的线束 | 器件端不可用 PCIe 6+2 替代；外观相近不代表接线相同 |
| GPU 辅助供电 | 本课显卡一个 8-pin，使用 PCIe 6+2 组合 | 不接 EPS 4+4，不使用来路不明转换线，不反向使用模组线 |
| CPU_FAN1 | CPU 散热器风扇连接；检查插接和线缆避开叶片 | 接到 SYS_FAN 并不等于满足本课的 CPU 风扇监测目标 |
| SYS_FAN | 机箱风扇；模式与风扇相匹配 | 三针 DC 与四针 PWM 的调速方式不同；不能把 RGB 插头当风扇供电 |
| JFP1 | 按本板手册定位 PWR SW；LED 接线区分正负极 | 开关线与 LED 线不是同一功能；相同外观的排针不能随意套用 |
| JAUD1 / JUSB | 对照标签、缺针或防呆结构连接机箱音频与 USB | 不能用旋转插头/错开一针来“适配”；本课不用 RGB 混插做真实演示 |
| SATA SSD | 主板 SATA 数据线 + 电源 SATA 供电 | 只接一条线不能完成连接；M.2 NVMe 无须这些线 |
| 显示接口 | 显示线接独显 HDMI / DP，显示器选相应输入源 | 本课 5600 无集成显示能力，主板视频口不能作为正常画面输出 |

以上接口定位以 [S1] 为板级依据，电源线用途以 [S6][S7] 为依据，独显和 CPU 的特定条件以 [S3][S5] 为依据。电源端有些模组插座可以共享 CPU/PCIe 标识，不能由此推导器件端插头可互换，也不能混用不同电源的模组线。

## 5. 20 工位装配流程

表内顺序是为本教学平台安排的一条可执行路径；能够在工位空间和依赖均满足的情况下调整个别无关步骤。UI 应同时展示“本步动作、前置条件、检查点”，不能只有一个部件飞入机箱的动画。

| 工位 | 动作与解释 | 进入本步的真实条件 | 完成检查 / 动画表现 |
| --- | --- | --- | --- |
| A01 | 建立安全工位、断开交流电源、准备 ESD 和工具 | 尚未接电；已有实训规范 | 显示断电与 ESD 检查，主板在工作垫上 |
| A02 | 核对 BOM、CPU 支持、内存类型、机箱空间和线束 | A01 完成 | 标出 AM4、DDR4、独显、BIOS 核对；不把未知版号伪装已确认 |
| A03 | 移除侧板，核对 ATX 安装孔/支柱及后 I/O 挡板 | A01、A02；机箱稳定平放 | 多余支柱移除；独立挡板在主板入箱前就位；若实物已集成不再叠装 |
| A04 | 在台面上装 CPU：解锁、对三角、落座、锁定 | A02；插座无异物，针脚无损 | CPU 以正确方向落入 AM4；不出现 Intel 压盖动作 |
| A05 | 拆下 AM4 两侧塑料扣具，托住并保留背板 | A04；明确使用四螺钉 Wraith Stealth | 塑料扣具离场、背板仍在位；不能把背板当作包装拆走 |
| A06 | 检查预涂导热膏 / 按要求重涂 | A04、A05；接触面清洁 | 本次新原装散热器采用预涂分支；画面解释无需重复加膏 |
| A07 | 安装散热器，四点先挂入，再按对角均匀固定 | A05、A06；背板孔位对齐 | 散热器平行压合；标出 1→3→2→4 的对角示意，无虚构通用力矩 |
| A08 | 连接 CPU_FAN1，整理短风扇线 | A07；风扇导线无损 | 风扇插头接 CPU_FAN1，导线避开扇叶 |
| A09 | 安装两条 DDR4 到 A2/B2 | A04；插槽可接近，无散热器干涉 | 先解开相应活动卡扣、对缺口后均匀插入；两端到位 |
| A10 | 在 M2_1 安装 2280 NVMe，恢复 M.2 散热片 | A02；显卡尚未遮挡；螺钉/支柱正确 | 拆片、核对散热垫保护膜、约 30° 插入、压平固定、复位散热片 [S1] |
| A11 | 安装 ATX 电源并预走主要线缆 | A03；交流线仍拔下，使用匹配线缆 | 电源进风口朝机箱设计的可用进气面；先为顶部 EPS 留出路径 |
| A12 | 将主板组件入箱并固定 | A03、A08、A09、A10；孔位/挡板与走线均就绪 | 抓边移动，PCB 对准支柱；按所用机箱/主板要求固定，不能拖拽散热器搬板 |
| A13 | 连接 ATX 24-pin 与 CPU EPS 4+4 | A11、A12；识别 CPU/EPS 标签 | 两个独立供电终点均显示锁扣到位；拒绝 PCIe→CPU 的错误选择 |
| A14 | 连接机箱 PWR SW、实际存在的 LED、前 USB 与 HD AUDIO | A12；掌握本板 JFP1/JAUD1/JUSB 图 | 按丝印和手册，不强制虚构机箱没有的 HDD LED/Reset 线 |
| A15 | 接机箱风扇；可选安装 SATA SSD | A11、A12；风向和接口已核对 | 主线检查 SYS_FAN；SATA 扩展必须同时有数据与供电，未选扩展不影响主线完成 |
| A16 | 移除对应 PCI 挡片，将独显插入 PCI_E1 并固定挡板 | A12；机箱空间够、线缆让开、PCIe 卡扣可操作 | 显卡进入后槽位对齐并固定；演示卡扣和挡板固定两个约束 |
| A17 | 连接显卡单个 PCIe 6+2 组成的 8-pin | A11、A16；确认是 GPU/PCIe 线束 | 插头到位且不绷紧；显卡已固定，不能让供电线承担重量 |
| A18 | 完成通电前总检与显示器连接 | A08、A13、A14、A15、A17 | 无异物、无多余支柱，线不碰扇；显示器接独显；教师工位按实训制度检查 |
| A19 | 接交流线、开电源、按机箱按钮；观察 POST 并进入 UEFI | A18 全部检查满足；手与工具离开内部 | 按 Delete 进入设置，记录 CPU、16 GB 内存、SSD、CPU 风扇与温度；POST/UEFI 是示意界面 [S1] |
| A20 | 正常关机、关闭电源并拔线；整理线缆、复位侧板、完成记录 | A19 完成或已安全停止故障检查 | 工具和余件清点；记录通过项/问题。安装操作系统可另开课，不伪称已安装系统 |

其中 A05～A08 的安装与重新安装分支依据 AMD 的 AM4 弹簧螺钉型流程：[S4]。先让四颗螺钉都正确接入，再对角逐次固定；不能先把一角拧到底再硬压其余角。屏幕上的编号表达顺序，不表示螺钉扭矩或必须旋转的圈数。

### 5.1 必须实现的依赖规则

- CPU 必须先于导热接触和散热器；散热器/背板/CPU_FAN1 未就绪时，不允许进入通电操作。
- 主板入箱前检查支柱；不能让“安装主板”状态在未检查支柱时被计为合格。
- GPU 必须先固定并插入 PCI_E1，再连接 GPU 供电；M2_1 检修需要先处理实际遮挡它的组件。
- EPS 与 PCIe 使用不同状态和连接端点；不能用“电源已装”代替所有供电完成。
- 练习中的错误动作应停在安全反馈阶段，说明原因后允许修正，不播放损坏、火花或错误插头成功插入的动画。
- “查看步骤”可跳到任意工位观察示意；“实训执行”必须核对依赖。跳转展示的状态不可冒充学员已实际完成的操作。

## 6. 规范拆卸：不是逐帧倒放

拆卸入口必须重新执行关机、O 档、拔交流线与 ESD 检查。软件可以把整机迅速展开以讲解结构，但“展开观察”不能记入真实拆卸成绩。热机拆散热器前，若需软化旧导热膏，只能在**完整、正常工作的散热系统仍装好时**短时开机，随后重新关机和完全断电，不能为了软化导热膏让裸 CPU 通电。[S4]

| 拆卸工位 | 操作 | 必须先解除的约束与检查 |
| --- | --- | --- |
| D01 | 安全关机、拔交流线、ESD、拆侧板 | 对应 A20/A01；不能在运行状态进入内部拆卸 |
| D02 | 拍照/记录接线、断开外部显示与外设线 | 为回装保留位置记录；连接线不牵扯机箱 |
| D03 | 按插头卡扣断开显卡辅助供电 | 对应 A17；抓插头外壳，不拉线芯 |
| D04 | 扶住显卡，卸挡板固定螺钉，解开 PCI_E1 卡扣后移出显卡 | 对应 A16；螺钉、供电和卡扣都已解除才可移动 |
| D05 | 断开可选 SATA 盘两条线并移除其支架/固定件 | 对应 A15；未配置 SATA 盘则明确跳过，不强制打卡 |
| D06 | 按记录断开前 USB、音频、PWR SW/LED、机箱风扇线 | 对应 A14/A15；区分有卡扣和紧配合插头，避免弯针 |
| D07 | 解开 EPS 与 ATX 锁扣并断开 | 对应 A13；供电线不能连着被主板带走 |
| D08 | 确认主板所有外连线已解除，取下固定螺钉并抓边取出主板组件 | 对应 A12；按实际孔位清点螺钉，不能靠拉散热器取板 |
| D09 | 拆 M2_1 散热片和 SSD 固定件，让 SSD 自然抬起，再按插入方向退出 | 对应 A10；不要从中段弯折或直接垂直拔出 SSD |
| D10 | 打开 DIMM 活动卡扣，从 A2/B2 均匀取出内存 | 对应 A09；主板置于稳定垫面，已解除卡扣 |
| D11 | 断开 CPU_FAN1，扶住主板和背板 | 对应 A08；避免散热器移出时拉扯风扇插针 |
| D12 | 对角逐次松开四弹簧螺钉，轻微左右转动散热器以解除膏体黏连，再轻抬 | 对应 A07；背板受控、螺钉均释放；严禁直接猛拔导致 AM4 CPU 被带出 [S4] |
| D13 | 清理需要回装的接触面，抬 CPU 锁杆，再抓边拿起 CPU | 对应 A06/A04；散热器已经离开；CPU 针脚放入适当保护包装 |
| D14 | 收纳背板/扣具/螺钉，断开电源余下线缆后卸下电源 | 对应 A05/A11；取电源前确认所有外连线与固定螺钉已解除 |
| D15 | 整理工位并登记部件、损伤和待维护项 | 对应 A03/A02；静电防护包装与零件分类完成 |

选择在机箱外完成 CPU/内存/M.2 的细部拆装，是本课为避免空间遮挡采用的路径。合规的其他维修路径可由教师说明，但不能省略断电、解除卡扣、支撑部件等前提。

## 7. POST、UEFI 与首次通电检查

POST 是上电后的自检/初始化过程；UEFI 是固件设置环境；SSD 被固件识别，不等于 SSD 中已经存在可引导操作系统。首次启动可能经历内存初始化，不能因为短暂黑屏就反复强制断电，也不设一个适用于所有机器的固定等待秒数。

本板以 Delete 进入 UEFI 设置，F11 进入启动菜单。课件中的 BIOS/POST 窗口须明显标注“教学模拟”，不得显示为实时读取学员电脑的硬件数据。[S1]

检查任务：核对 Ryzen 5 5600、总内存 16 GB、预期 SSD 和风扇转速；观察温度趋势与风扇工作，核对是否出现持续异常。不开启自动超频作为通过条件；A-XMP 是额外配置项目，先以默认设置建立可启动基线。

Ryzen 5 5600 官方 Tjmax 为 90°C。它是该 CPU 的规格上限，不是装配验收目标或所有 CPU 的通用安全阈值；不设计“低于 90°C 一律合格”的题目。[S3] 本课显卡具有低温停转功能，因此显卡风扇静止本身不能单独判定为故障。[S5]

## 8. 故障实训：用现象选择下一步验证

| 场景 | 优先核查顺序 | 教学结论与反馈 |
| --- | --- | --- |
| 完全无反应 | 插座/交流线、PSU 开关、24-pin/EPS、JFP1 PWR SW、短路/异物迹象 | 先按安全流程断电检查；“电源已安装”不能证明所有连接正确 |
| 风扇转但无画面 | 显示器电源/输入源、显示线是否接独显、显卡座合与 8-pin、EZ Debug 状态 | 5600 的主板视频口不是正常显示输出；风扇转不等于 POST 通过 |
| DRAM 状态持续异常 | 完全断电后核对 A2/B2 与插到底；按手册用单条 A2 进行最小化排查 | 用单条测试区分模块/插槽/设置方向，不能直接宣布主板或内存损坏 |
| CPU 状态持续异常 | EPS 供电、CPU 安装与针脚、散热固定、CPU/BIOS 支持条件 | 由教师处理针脚与固件支持；不让学员通电插拔 |
| VGA 状态持续异常 | 独显供电、座合和固定、显示链路，再按手册排查关联设备 | 该板手册的 VGA 指示范围还涉及 GPU/PCIe/M.2；不要把灯名当作部件损坏证明 [S1] |
| BOOT 状态/找不到启动项 | UEFI 是否识别 SSD、是否已安装可引导系统、启动方式/启动次序 | 新空盘可无启动项；区别“未识别磁盘”和“没有操作系统” |
| CPU 风扇无转或温度快速异常 | 安全关机断电，核对 CPU_FAN1、导线/叶片、散热接触及安装 | 不靠延长运行来“看看会不会好”；只做已授权的安全检查 |
| 前面板灯不亮但能开机 | 对照 JFP1 手册检查 LED 正负与机箱实际接线 | LED 反接与 PWR SW 错接是不同问题，不把灯不亮描述为必然无法开机 |
| 可选 SATA 盘不可见 | 断电核对 SATA 数据与电源、端口、UEFI 识别 | 只接供电或者只接数据，都未完成这一扩展装配 |

EZ Debug 的 CPU/DRAM/VGA/BOOT 指示用于缩小排查范围；启动过程中的短暂切换与持续异常需区分。排故以一次只改变一个因素、保存记录和复核结果为原则。清 CMOS 仅在适当场景按本板手册执行，操作前必须断电；不是所有黑屏的首个动作。[S1]

## 9. 实训测评与评分

总分 100：安全规范 20、部件与兼容性 15、装配顺序/连接 30、POST 与排故 20、拆卸与工位复原 15。建议 80 分且关键安全项全部正确为本课合格线；这是课程评分设定，不是国家或厂商认证。

安全关键项包括：内部操作前断开交流电源、禁止 EPS/PCIe 器件端混插、CPU 方向/针脚保护、散热器及 CPU_FAN1 就绪后才通电、显卡卡扣未解除不强拔、AM4 散热器不猛拔。关键项错答需解释并重练，最终报告保留错误/修正记录，不因点击“重置”抹除本次测评事实。

题库至少覆盖以下任务，每题在反馈中说明原因：

| 题目 | 正确答案要点 |
| --- | --- |
| 两条 DDR4 应安装到哪里？ | 本板 A2/B2，依据该板手册，不是相邻任意两槽 |
| 5600 装好为何接主板 HDMI 无画面？ | 该 CPU 需要独显，显示线应接独显 |
| 四弹簧螺钉散热器装前要拆什么、保留什么？ | 拆两侧塑料扣具，保留 AM4 背板 |
| 24-pin 接好后为何还需 CPU 供电？ | CPU_PWR1 仍需 EPS 4+4；不能改用 GPU PCIe 6+2 |
| M.2 SSD 是否都使用 NVMe？ | 否，外形与协议要分别核对；本课选 NVMe，装 M2_1 |
| 显卡怎么拆？ | 断电→拔辅助供电→扶卡卸挡板螺钉→解 PCIe 卡扣→移出 |
| 新空 SSD 导致没有启动项能否判定损坏？ | 不能，先区别识别到磁盘与存在可引导系统 |
| CPU 散热器为什么不能直接猛拔？ | AM4 上旧导热膏可能黏连 CPU，须解螺钉并轻微旋转后抬起 |
| 650 W 能否直接推广给所有电脑？ | 不能，按整机负载、瞬态需求、接口和厂商要求选型 |
| 怎样证明首次装配成功？ | 明确 POST/UEFI 检查记录，不能只以风扇转动判定 |

## 10. 不可泛化参数与建模禁区

1. **插槽命名和插法：** A2/B2、PCI_E1、M2_1、CPU_FAN1 与 JFP1 都是本板语境，其他板应重新查手册。
2. **AM4 背板：** 本课的可拆塑料扣具与背板路线不可复制到 AM5 固定背板、Intel LGA 或其他散热器套件。
3. **力矩/压力：** 不给所有主板螺钉、CPU 散热器、内存插入动作统一数值；工具和参数来自对应产品说明。
4. **导热材料：** 不把预涂、保护膜、用量和涂抹图案当成所有散热器共用规则；本课采用检查预涂分支。
5. **电源：** TDP 不是整机实际功耗；650 W 与该显卡 550 W 建议都不能直接推广，80 PLUS 等级也不是额定功率或整机稳定性的单独保证。
6. **显卡：** 单 8-pin 是本课特定型号；其他显卡可能使用不同数量 8-pin 或 12V-2x6 等接口，不能外观套用。
7. **M.2 与通道共享：** 本板 M2_2 装 PCIe SSD 时会影响 PCI_E3；本课主线使用 M2_1。其他主板的 SATA/PCIe 共享限制需另查。
8. **风扇与灯效：** CPU 4-pin PWM、3-pin DC、5 V ARGB、12 V RGB 不可混淆；本课不以 RGB 作为装配必需项。
9. **温度/时间：** 不设置跨平台通用的 POST 秒数、怠速温度或待机风扇转速；CPU 90°C 规格上限不可作为验收目标。
10. **UEFI/BIOS：** 固件界面与菜单随版本变化，动画是教学模拟；未核实的最低 BIOS 版号不进入课件事实字段。
11. **几何真实性：** 模型须呈现 CPU 在插座内、散热器在 CPU 上、两条 DIMM 在 A2/B2、NVMe 在顶部 M.2、GPU 与主板垂直且对准后挡槽、电源在仓内；不可用随机立方体飞散代替结构。
12. **课程能力边界：** 本课训练台式机部件装配，不延伸为电源内部维修、硬件认证、驱动自动扫描或真实电脑远程控制。
