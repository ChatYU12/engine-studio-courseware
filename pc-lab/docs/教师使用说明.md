# PC LAB · 教师使用说明

适用版本：本课 AM4 / DDR4 / ATX 平台，20 个装配工位、15 个拆卸工位、16 道知识题、8 类排故。本文依据当前应用的交互与评分实现编写；知识事实与来源以《01-课程知识体系》为准。

## 1. 课前准备

打开根目录 `电脑主机拆装实训.html` 即可使用离线课件。先在实际授课电脑上检查三维能否显示、标签与投影是否清楚、鼠标旋转/缩放、播放和文件下载是否可用。若本机存储受限，课堂结束前安排导出报告。需要开发或更新课件时，在项目目录运行 `npm ci`、`npm run check`、`npm run build`；`npm start` 提供 `dist` 的本地服务器，地址为 `http://localhost:8893`。

实物工位使用 ESD 工作垫与符合实训室要求的接地点、手环、合适螺丝刀、螺钉分类盒和原厂说明书。课前检查硬件完好，核对 CPU / BIOS 支持、内存和机箱空间、匹配电源线材；不要在课堂上依靠未核实的 BIOS 版本号临时试错。

本课固定平台为 MSI B550-A PRO、Ryzen 5 5600、Wraith Stealth 四弹簧螺钉散热器、2 × 8 GB DDR4-3200、M2_1 的 2280 NVMe、RTX 3060 VENTUS 2X 12G OC，以及 CX650M（2021）650 W ATX 电源。机箱为标准中塔教学结构，参照 4000D 空间，不是完整 CAD 复刻。可选 SATA 扩展只训练额外盘体、数据和供电连接。

若学校实物与本课不同，应在开课前列出差异，重新查对应产品手册，特别是 CPU 插座、背板、散热器扣具、内存推荐槽、M.2 协议、显卡供电、前面板针位与固件支持；不要用模型替代实物核对。

## 2. 四种模式怎样配合教学

| 模式 | 主要任务 | 推荐讲法 |
| --- | --- | --- |
| 自由观察 | 建立整机空间关系，识别 21 类对象 | 让学员指出 CPU/散热器、A2/B2、M2_1、PCI_E1、24-pin、EPS、GPU 电源位置 |
| 爆炸拆解 | 认识层级与安装方向 | 用连续滑杆逐渐展开，说明主板子装配、独显和机箱支撑关系；展开顺序不计作规范拆卸 |
| 分步装配 | 学习 A01—A20 的动作、前提、检查和原理 | 先演示后练习，暂停在接口、固定点和供电端点，要求学员口述检查点 |
| 规范拆卸 | 学习 D01—D15 的真实解除约束 | 强调重新断电；显卡先拔线、扶卡卸螺钉、解卡扣；AM4 散热器先对角松螺钉再解黏连 |

点击模型或左侧部件清单可查看对应知识卡与厂商来源。“聚焦”定位选中部件，“隔离”只观察当前部件，再次点击退出；复位返回整体视角。预设包括立体、主板侧、后部、俯视。标签可开关，便于先认知后提问。

播放/暂停和 0.5×、1×、1.5×、2× 速度用于演示；工位滑杆可观察当前动作的中间状态。选择“减少动态”后，播放显示当前步骤终态，仍可阅读和完成检查。截图保存三维画布 PNG，不包含整页知识卡或考核弹窗；课堂作业另交学习报告。

在 SATA 部件卡开启扩展支线，便于比较 NVMe 与 SATA。未开启时，规范拆卸 D05 可以“记录未配置并继续”，不要求对不存在的盘勾选拆卸检查。

## 3. 进入实训与安全门

先选择装配或拆卸方向，再点击“实训考核”。每次进入必须重新确认 5 项安全条件：正常关机/PSU O 档/拔交流线、ESD、抓边保护、工位与工具、封闭电源模块及异常停止。软件记录的是学员确认，教师应现场检查真实工位。

实训按方向顺序推进。学员完成当前工位检查后点击“确认本工位完成”；未确认的前置工位不能跳过记分。观看、播放或自由演示跳转本身不会增加完成数。可退出实训观察结构，再继续已有记录；“从头重练”仅重置当前方向工位并保留近期历史，装配重练会清空该方向通电前总检。

到 A18 需逐项确认 8 项通电前总检：支柱与异物、CPU 与散热/CPU_FAN1、A2/B2、M2_1、24-pin 与 EPS、显卡固定及 PCIe 供电、前面板/风扇/可选 SATA、独显显示输出与工具离场。A18 以后仍需保持总检成立，才可确认通电相关工位。

进入 A19 后可打开 POST / UEFI 教学模拟。示例型号和 SSD 识别状态用于讲解；CPU 风扇转速与温度明确要求现场确认，不从当前电脑读取。指导学生区分四件事：部分电路得电、POST 完成、进入 UEFI、成功引导操作系统。本课不安装操作系统，新空盘没有启动项不等于硬件故障。

## 4. 教师在实物上必须核验的项目

| 操作节点 | 教师观察和提问 |
| --- | --- |
| 内部操作开始 | 交流线确已拔下；ESD 接法符合实训室要求，不以显示器黑屏代替断电 |
| CPU 安装 | 正确 AM4 方向，自然落座，锁杆到位；针脚无接触或强压 |
| 散热器 | 拆塑料扣具但保留背板；导热材料检查合理；四点对角固定；CPU_FAN1 已接 |
| 主板与内存 | 支柱逐一对孔，无多余支柱；内存为 A2/B2 且两端到位 |
| 存储 | NVMe 协议/长度符合 M2_1；固定件正确，不弯盘；SATA 支线如有则两线齐备 |
| 供电 | 24-pin、EPS 4+4、PCIe 6+2 的标签、终点与锁扣；无未知模组线混用 |
| 显卡 | PCI_E1 座合、后挡板固定、单 8-pin 到位，线缆不承重且不碰扇叶 |
| 首次通电 | 实物总检通过；手与工具离开内部；观察 POST / UEFI 与散热趋势，发现异常安全停止 |
| 拆卸显卡 | 拔辅助供电、扶卡卸螺钉、释放卡扣后再移动 |
| 拆卸散热器 | CPU_FAN1 断开、背板受控、四螺钉释放、轻微转动解黏连后抬起；CPU 留在插座 |
| 工位复原 | 敏感器件妥善包装，螺钉工具清点，问题与待维护项有记录 |

不安排学生打开电源外壳、带电插拔内部器件、强插错类接口、裸 CPU 通电或为了制造故障损坏实物。错误接线可在选择题中推演。需要软化散热器旧膏时，必须先保持完整正常散热系统，按条件短时运行后重新关机、关闭电源和拔线，再进行拆卸。

## 5. 知识题、排故与形成性评分

16 道知识题可提交后查看解析、修正并再次提交；其中 8 道带关键安全标记。该单项以 **80 分且关键安全题全部正确** 显示达到要求。未答题计为未正确，软件保留近期提交历史。

8 类故障题要求选择“下一项优先检查”：完全无反应、风扇转无画面、DRAM、CPU、VGA、BOOT/空盘、CPU 散热异常、SATA 扩展不可见。选择后立即反馈原因，并保存选择和修正历史；其中涉及断电与危险操作的关键排故必须正确。引导学生从现象提出可验证动作，不能把一个指示灯直接当成部件损坏证据。

学习报告采用下列形成性分值：

| 项目 | 权重 | 应用中的计算依据 |
| --- | --- | --- |
| 安全规范 | 20 | 本次 5 项安全条件全部确认得 20，否则为 0 |
| 知识理解 | 15 | 最近一次已提交知识自测的百分制分数 × 0.15；未提交为 0 |
| 装配流程 | 30 | 已确认 A 工位数 ÷ 20 × 30 |
| 故障判断 | 20 | 当前正确排故数 ÷ 8 × 20 |
| 规范拆卸 | 15 | 已确认 D 工位数 ÷ 15 × 15 |

加总后四舍五入为报告总分。报告显示“满足本课数字学习完成条件”时，必须同时满足：本次安全全部确认、20 个装配工位与 15 个拆卸工位全部确认、最近一次知识提交的关键安全题全对、当前关键安全排故全对、总分至少 80。知识自测的单项达标与形成性总分是不同维度，教师可结合两者要求补练。

这些权重与阈值属于本课课程设定，不是国家技能证书或厂商认证标准。浏览器检查勾选是形成性证据；实物操作成绩由教师根据观察、解释和实际结果评定。关键项包括断电、CPU 针脚保护、AM4 背板与散热、EPS/PCIe 区分、CPU_FAN1、显卡卡扣与散热器解黏连；安全关键动作失误应先停止、纠正和重练，再讨论熟练度。

## 6. 两课时组织建议

建议 2 × 45 分钟；实物数量不足时分小组轮换，一人操作、一人对照检查、一人记录，随后换岗。以下是课堂安排建议，不把动画时长当作真实操作时长或计时合格线。

| 课时 | 时间 | 活动与产出 |
| --- | --- | --- |
| 第 1 课时 | 0—8 分钟 | 明确目标、固定平台与安全；识别断电和 ESD 条件 |
| 第 1 课时 | 8—18 分钟 | 自由观察/爆炸视图：指出 12 类以上部件与关键接口 |
| 第 1 课时 | 18—32 分钟 | A04—A10 主板子装配演示，重点 CPU、背板、A2/B2、M2_1；暂停并口述检查点 |
| 第 1 课时 | 32—45 分钟 | A11—A20 机箱整合与供电、总检和模拟 UEFI；完成一组接口判断 |
| 第 2 课时 | 0—8 分钟 | 回顾 EPS / PCIe、独显输出、POST 与空盘；以故障题复习 |
| 第 2 课时 | 8—23 分钟 | 小组分步实训与教师巡查；设备不足时使用浏览器工位记录 |
| 第 2 课时 | 23—35 分钟 | D01—D15 规范拆卸，重点显卡卡扣与 AM4 解黏连；完成工位复原 |
| 第 2 课时 | 35—45 分钟 | 16 题自测、排故修正、导出报告；教师结合现场表现讲评 |

课后可布置“三张结构截图 + 一份报告 + 一个排故解释”：A2/B2、EPS/PCIe 两终点、AM4 背板层级各一张；让学员用自己的话说明一次错误如何修正。

## 7. 本机数据、重练与报告

课件将安全/总检勾选、工位完成、知识答案与提交、排故答案/尝试和操作事件保存到此浏览器的本机存储。没有课程账号或云端同步；更换浏览器、改变页面来源、隐私模式、清除站点数据或本地文件存储策略变化都可能影响记录。课堂共用设备应按学校安排隔离浏览器使用者，并在换人前导出报告。

点击“学习报告”下载 Markdown，包含北京时间生成时间、固定平台、分值、完成条件、安全/总检表、A/D 工位、近期自测提交、排故修正和操作事件、官方来源及教学边界。原始事件使用 ISO 时间戳。当前最多保留 50 次知识提交、150 条排故尝试和 800 条操作事件，较早记录会移出本机历史，因此需要及时归档导出的报告。

视角复位、模式切换和演示重播不会删除成绩。实训“从头重练”清除该方向工位检查与完成数，并保留重练事件；不是删除所有历史。当前没有学习报告导入功能，导出文件用于查看、提交与归档。存储不可用时应用会提示仅会话记录，关闭前务必导出。

## 8. 官方依据与教学边界

页面“知识来源”汇总 9 条官方资料；部件和步骤带 S 编号链接。完整核验记录见《01-课程知识体系》：MSI 主板手册/规格/支持页、AMD 5600 规格与 AM4 散热器指导、MSI 显卡数据页、CORSAIR 电源/机箱指南及 Seasonic 线缆用途说明。

教学模型表达部件功能、安装层级和大致机械关系，不复刻制造尺寸、公差、全部电路、精确线束和真实工具力矩。动画不验证教师手中的 CPU、插头、背板或固件是否相同；650 W、本卡单 8-pin、A2/B2、M2_1 和 CPU 90°C Tjmax 都不能直接推广到其他平台。90°C 为该 CPU 规格上限，不是课堂合格温度目标。

POST / UEFI 与监测项目均为教学模拟，不能当成实物测量。浏览器、设备与窄屏等实际验证结果参阅《迭代与验收记录》和 QA 材料；本文不把尚未完成的测试写成通过，也不宣称行业认证。在线发布状态与版本以主任务最终交付为准，离线单 HTML 是独立使用入口。
