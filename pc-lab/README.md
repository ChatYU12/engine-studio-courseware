# PC LAB · 3D 电脑主机搭建与拆解实训

基于 Three.js 的中文交互式 HTML 课件，围绕一套固定 AM4 / DDR4 / ATX 平台，提供 21 类部件识别、20 个分步装配工位、15 个规范拆卸工位、16 道知识自测和 8 类故障判断练习。

## 直接打开离线课件

双击项目根目录的 **`电脑主机拆装实训.html`**，使用支持 WebGL 与 JavaScript 的浏览器打开即可。`index.html` 是相同内容的入口；`dist/index.html` 是构建后的发布入口。

构建成品将运行所需 JavaScript、CSS 与程序几何一并嵌入单个 HTML，支持 `file://` 离线使用，无需先安装 npm 依赖。页面内的厂商来源链接需要联网访问。若浏览器未能初始化 WebGL，页面会给出提示，仍可阅读知识与完成题目。

**验证说明：** 已在本地 HTTP 中实测完整装拆、测评、导出和响应式布局。自动化浏览器安全策略禁止 `file://` 协议，因此文件直接打开未获自动实测；构建已验证无外部运行依赖、无模块加载，存储不可用降级已做回归。若浏览器限制本地文件，请按下方方法启动本地 HTTP 服务。

本机学习记录受浏览器存储策略影响，尤其是隐私模式与本地文件页面。关闭页面前可点击“学习报告”导出 Markdown 记录；截图按钮只导出三维画布。

## 修改源码与构建

开发环境需要可用的 Node.js、npm；本地服务器命令另需 Python 3。在本项目目录执行：

```bash
npm ci
npm run check
npm run build
npm start
```

首次 `npm ci` 需要取得锁文件指定的构建依赖。`check` 检查 JavaScript 语法和课程数据/状态约束；它不代替浏览器验证。`build` 更新根目录两个 HTML 入口及 `dist/index.html`。`start` 将 `dist` 通过 Python 本地服务器提供在 [http://localhost:8893](http://localhost:8893)，终端按 Ctrl+C 停止。

源码修改后须重新构建，双击成品不会自动读取 `src` 中的更改。在线入口为 [GitHub Pages 预览](https://chatyu12.github.io/engine-studio-courseware/pc-lab/)；离线使用不依赖该地址。

## 主要操作

| 功能 | 用法 |
| --- | --- |
| 自由观察 | 拖动模型旋转，滚轮缩放；使用立体、主板侧、后部、俯视预设与“复位” |
| 部件识别 | 点击模型或“部件清单”，查看用途、接口、注意事项与官方来源；“隔离”聚焦当前部件 |
| 爆炸拆解 | 连续滑杆控制合拢/展开，用于认识结构层级；真实操作顺序在“规范拆卸”中学习 |
| 分步装配 | 按 20 个 A 工位学习；播放/暂停、前后切步、滑杆与 0.5×—2× 速度控制 |
| 规范拆卸 | 按独立编排的 15 个 D 工位学习断电、解线、解扣与拆除 |
| 可选 SATA | 在 SATA 部件知识卡启用支线，显示盘体、数据与供电；不增加必装工位 |
| 减少动态 | 手动开关或跟随系统初始偏好；减少动态时播放显示步骤终态 |
| 截图与报告 | 截图导出当前三维画布 PNG；学习报告导出工位、自测、排故与修正记录 |

键盘：Tab 移动焦点，Enter 激活控件；焦点未停在表单/按钮等控件上且没有弹窗时，空格播放/暂停，左右方向键切步。实训中右方向键执行当前工位确认，不会跳过未满足的检查。

## 实训与形成性评价

自由演示可以跳转，不会记为完成。点击“实训考核”后，先确认本次 5 项安全条件，再逐工位勾选检查并“确认本工位完成”。装配到通电前须完成 8 项总检；POST / UEFI 窗口明确为教学模拟，不读取当前电脑硬件。

课程报告使用：安全 20、最近一次知识自测 15、装配 30、当前排故 20、拆卸 15。数字学习完成条件包括安全全部确认、20 个装配与 15 个拆卸工位全部确认、知识关键安全题和关键排故全部正确、形成性总分至少 80。知识自测另以 80 分且关键安全题全对标为该项达标。真实设备操作应由教师现场核验，浏览器勾选是学员自报记录。

学习数据保存在当前浏览器的本机存储，不通过课程服务同步。从头重练会重置该方向工位，同时保留近期历史；视角复位与演示重播不会清空成绩。详细评分公式、历史容量与课堂安排见 [教师使用说明](docs/教师使用说明.md)。

## 固定平台与资料

主板为 MSI B550-A PRO，CPU 为 Ryzen 5 5600，Wraith Stealth 使用 AM4 背板与四弹簧螺钉；两条 DDR4 位于 A2/B2，2280 NVMe 位于顶部 M2_1；RTX 3060 VENTUS 2X 12G OC 使用单 8-pin，电源示例为 CX650M（2021）。显示器接独显，EPS 4+4 与 PCIe 6+2 的器件端不能互换。

平台参数不可直接推广到其他电脑。课前应核对实训主板 BIOS 对 CPU 的支持，课程不写未经核实的最低版号。

## 项目结构与适用边界

`src/content.js` 保存课程数据，`src/pc-scene.js` 创建三维结构，`src/app.js` 管理界面与学习流程，`src/state.js` 管理教学状态；`scripts/build.mjs` 生成单 HTML，`src/vendor` 提供本地 Three.js 与许可，`design` 保存前置效果方案。

模型是程序生成的教学几何，表达结构、接口方向和动作层级；不提供制造 CAD、公差、完整电路、装配压力或通用拧紧力矩。课程不包含电源内部维修、真实设备检测或操作系统安装。生产质量验证以实际验收记录为准，本文不宣称尚未完成的浏览器测试或行业认证。
